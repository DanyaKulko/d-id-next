## Примечания по реализации

1. **Матчинг для латиницы и кириллицы** — word boundary regex `\b` работает корректно.
2. **Матчинг для Devanagari (Hindi/Marathi)** — `\b` НЕ работает. Использовать границы: начало строки / конец строки / пробел / знак препинания.
3. **Многословные фразы** (например "покажи фото", "photo dikhao") — матчить после нормализации пробелов.
4. **Управление через админку** — хранить в таблице `KeywordTrigger` (id, language, category, keyword, isActive) и перезагружать in-memory Set при изменении.
5. **Приоритет категорий** при множественных матчах: `search_information` > `photo/video_from_blog` > `photo/video_from_external` > `none`. При неоднозначности — отправлять в LLM-классификатор для разрешения конфликта.
