How the site looks on mobile WITHOUT responsive layout

This is an isolated demo (the live site is untouched). It shows how the pages look on a phone if the responsive mobile layout is removed and the desktop version is simply squeezed to the screen width — exactly what was requested. Each “phone frame” below is the real 1280px-wide desktop page fitted into a phone screen. You can see that the text and controls become too small — reading and tapping is barely possible without zooming.

💡 Best viewed on a real phone: tap “Open on phone” under any page — the browser will fit the desktop into the screen and shrink everything, just like in these frames.
