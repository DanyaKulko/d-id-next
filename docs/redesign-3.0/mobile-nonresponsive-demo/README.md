# Демо: десктоп без адаптива на мобильном

Изолированный прототип для показа клиенту. **Рабочий сайт не затронут** — это
отдельная статическая папка, не входит в Next.js-сборку и не деплоится.

## Зачем

Клиент просит убрать мобильную адаптивную вёрстку и просто «ужать десктоп в
экран телефона». Это демо показывает, как это будет выглядеть: элементы и текст
становятся слишком мелкими, без зума пользоваться неудобно.

## Что внутри

| Файл | Что показывает |
|------|----------------|
| `index.html` | Лендинг: все 3 страницы в рамках телефона + ссылки открыть на реальном телефоне |
| `home.html` | Главная — сетка из 5 ролей |
| `role.html` | Страница роли (Space), idle-состояние |
| `login.html` | Экран логина |
| `assets/css/*` | Реальные CSS из `src/`, скопированы **без изменений** |
| `assets/demo.css`, `assets/demo.js` | Только «клей»: регистрация шрифта + порт мелких клиентских скриптов (звёзды, бегущая строка, Lottie-лампа). Не часть проекта. |

## Единственное отличие от рабочего сайта

В `<head>` каждой страницы стоит фиксированный десктопный viewport:

```html
<meta name="viewport" content="width=1280" />
```

вместо адаптивного `width=device-width`. Именно это заставляет мобильный браузер
вписать десктоп-лейаут (1280px) в ширину экрана и всё ужать — то, что и нужно
продемонстрировать.

## Как смотреть

```bash
cd docs/redesign-3.0/mobile-nonresponsive-demo
python3 -m http.server 8745
# затем открыть http://localhost:8745/index.html
```

Лучше всего открыть `index.html` на компьютере (видно сразу все три в рамках
телефона), а ссылки «Открыть на телефоне» — с настоящего смартфона. Нужен
интернет: видео и фото-превью ролей грузятся с CDN D-ID, как на реальном сайте.

## Источник вёрстки

Скопировано с ветки `redesign/3.0-space` (космический рескин 3.0).
Данные ролей (названия, описания, медиа) — из таблицы `agents`.
