# Neil Avatar 3.0 — «Космос» / Space Reskin · СПЕКА

> Цель: через смену CSS (и минимальные классы в HTML) сделать публичный сайт
> неузнаваемым — тёмный космический стиль, звёздное небо, угловые HUD-акценты.
> Эффект «WOW» при сохранении вёрстки, логотипа, шрифта и логики.

## 0. Жёсткие ограничения (из брифа)

- ❌ НЕ ломать вёрстку.
- ❌ НЕ трогать сложный JS (D-ID стриминг, микрофон/Azure, fullscreen, WebGL-keying).
- ❌ НЕ менять логотип (Lottie `/lottie/lamp.json` — цвета внутри JSON, CSS не трогает).
- ❌ НЕ менять шрифт (Nasalization, грузится через `next/font/local`).
- ❌ НЕ удалять/добавлять контентные элементы (можно добавить класс/обёртку-тему и фон-слой).
- ✅ Приоритет — мобайл и планшет.
- ✅ Поддержка Safari (iOS).

## 3. Сигнатурные элементы стиля

1. **Звёздное небо** — порт `starfield.js` в `'use client'` компонент `Starfield`:
   canvas, `requestAnimationFrame`, плотность ~1 звезда/6500px², твинкл + лёгкий парал-дрейф,
   `prefers-reduced-motion` → статичный кадр, DPR-scaling (cap 2), Safari-OK.
   Палитра звёзд: белый + холодный голубой `#9fd8ff` + тёплый `#ffd9a8` (намёк на бренд).
2. **Фоновый слой** `position:fixed; inset:0; z-index:-1` — градиент-вашес (deep navy) + ambient-glow пятна (amber/blue) + сетка-grid с маской-виньеткой + canvas-звёзды. Покрывает overscroll на iOS (не светит белым).
3. **Угловые HUD-скобки** — `.corner`-элементы или `::before/::after` c border, amber, opacity 0.5→1 на hover/focus. Чистый CSS. На карточках главной, на аватар-сцене, на интерактивных кнопках.
4. **Свечение и подъём** — `box-shadow` glow на hover кнопок/карточек, `translateY(-4px)`.
5. **Статус-LED** — пульсация (амбер/блю/грин-состояния остаются как функциональные индикаторы).

## 4. Архитектура внедрения (surgical)

- Новый файл `src/app/theme-space.css` — переопределяет существующие `--na-*` токены и базовые
  стили внутри `.na-theme-space` (НЕ глобально). Существующие компоненты, читающие токены,
  перекрашиваются автоматически.
- `(client)/layout.tsx` — оборачиваем `children` в `<div className="na-theme-space">` и монтируем
  `<SpaceBackground/>` (фон + звёзды) один раз. Это единственная HTML-правка для главной/роли/попапа/прелоадера.
- `/login` — отдельный роут: вешаем тему на `.na-login-shell` + монтируем фон.
- Точечные правки per-file там, где цвета захардкожены мимо токенов (см. PLAN).

## 5. Критично НЕ трогать (из разведки)

- `.na-status-indicator` (цвета состояний idle/listening/thinking/speaking/error).
- `.na-stage-btn--active` (индикация mute).
- inline-стиль `.na-transcript-overlay` (рендерится из JS).
- WebGL `.na-canvas-layer` — никаких CSS-фильтров на него; glow только на родителе/соседе.
- `body.na-body-pseudo-fullscreen`, `.na-stage-wrapper.is-loading` (blur при загрузке).
- z-index иерархия слоёв AvatarStage (background 14 / stream 15 / canvas 15 / overlay 18+).

## 6. Safari / мобайл

- `backdrop-filter` всегда с `-webkit-` префиксом.
- Высоты — `100dvh` с `@supports`-фолбэком на `100vh` (как уже сделано в pseudo-fullscreen).
- Никаких новых `clip-path` на видео/canvas; HUD-скобки — на border, не на clip-path.
- Touch-таргеты ≥ 44px сохраняем.
- Сохраняем все существующие breakpoints (1024/1080/900/768/720/640/480, desktop-first).

## 7. Критерий приёмки

- Сайт визуально «неузнаваем», тёмный космос, звёзды анимированы, HUD-углы на интерактиве.
- Вёрстка идентична (никаких сдвигов/переполнений) на мобайл/планшет/десктоп.
- Логотип и шрифт не изменены. Админка не изменена.
- Контраст текста проходит AA. `prefers-reduced-motion` уважается.
- Сборка проходит, D-ID/микрофон/fullscreen работают как раньше.
